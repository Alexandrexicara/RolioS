# RollOS

Sistema operacional experimental para dispositivo móvel com tela enrolável.

## Estado atual
Repositório inicial do projeto. O desenvolvimento começa com um protótipo de interface em desktop, simulação de tela variável e integração opcional com NVIDIA NIM.

## Limites importantes
Este protótipo não é ainda uma imagem instalável para celular. Kernel, drivers de painel flexível, motores, modem, GPU e sensores dependem do hardware real e da documentação do fabricante.
